# 参考出图读成墨线段和文字（2026-10-12）

`pid-plot::read::read_plot` 读第一页。坐标是纸面毫米，原点在左下，y 向上。曲线按 0.05 mm 弦高拆成直线。几乎铺满图幅的轴线段是打印驱动留下的图框四边形，PyMuPDF 把它计成 quad 而不是直线，读取器同样不把它算进线段数。

文字按基线、字号和字体聚成段。PyMuPDF 会把一段较宽的空隙单独算成一个空格段：同字体的空隙大约 3–8 pt，另一种是 10.56 pt 的一段字后面约 1.92 pt 处接上 10.17 pt 的一段。这两种空隙各算一个空格段，更宽的跨字体空隙不算。
