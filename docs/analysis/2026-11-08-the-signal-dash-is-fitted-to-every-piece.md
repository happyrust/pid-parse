# 信号线虚线按每段直线拟合（2026-11-08）

## 结论

前 10 张参考图剩下的 uncovered（3.217–42.020 mm）全部是 `1.905/1.270` 信号线虚线的划段端头。根因在我们：这种虚线在 `JStyleSimpleDashType` 里是拟合模式 2，`style.dll` 在每个折线顶点重新起相位，并把图案拉伸到每段直线上恰好铺满整数个周期。我们原先把整条折线当一个 subpath，相位连续，图案也不拉伸。改成按段拟合之后，10 张图的 coverage 都是 1.000000，uncovered 都是 0.000 mm。

## 记录字段

`JStyleSimpleDashType`（PSM `0x002F`）载荷中有两个字段：

| 偏移 | 类型 | 含义 | 语料取值 |
|---|---|---|---|
| `+26` | `u16` | 标志字，低 4 位是拟合模式 | `1.905/1.270` 与复杂虚线为 `0x0022`（模式 2），`3.5/1.75`、点划、双点划为 `0` |
| `+34` | `f64` | 拟合比例 r | `1.905/1.270` 为 `1.1666666269302368`（`f32` 的 7/6），其余为 `0.5` |

字段用法来自 IDA 反编译 `style.dll`：铺开函数 `sub_1001A470` 取 `flags & 0xF`，模式 2 时调用 `sub_10017A50`；`this+112` 就是 r，原样代入公式，不做其它换算。偏移由语料确定：逐条读出验收语料 `0x002F` 记录的原始头部，`+26` 的低 4 位和 `+34` 的 f64 与反编译出的成员一一对应。

## 公式（`sub_10017A50`）

设 f 是首段长度的绝对值，S 是一个周期中负段的总长（奇数段数时翻倍），P 是正段的总长，L 是这段直线的长度：

- 周期数 n = trunc((f − 2fr + L + S/4) / (S + P))
- n ≤ 0 时不拟合，图案按原长铺开
- 首段为负时，fit = (L − nP) / ((nS − f + 2fr) / S) / S。全负图案下化简为 fit = L / (nS − f + 2fr)
- 负段乘 fit，正段保持原长

r = 7/6 时，代码里的 n 比肉眼看到的节数少 1；分母 nS − f + 2fr = (n+1)S − g/2（g 为空隙长），所以每段末尾都留出半个空隙。

## 实现

- `pid_parse::style_link::DashPattern` 新增 `fit_mode()` / `fit_ratio()`，`read_dash_pattern` 读 `+26` / `+34`。新增 `with_fit()`，用于手工构造带拟合信息的图案。
- `pid_plot::model::PaperStroke` 新增 `dash_fit: Option<DashFit>`，只有模式 2 才有值。`DashFit::scale` / `pattern_mm` 实现上面的公式。
- `write.rs`：带拟合的直线或折线，每段直线单独写一个 `d` 和一个 subpath，相位 0。`stroked_segments` 按同样规则逐段遍历，读回结果与写出逐段一致（测试 `a_fitted_dash_restarts_on_every_vertex`）。圆弧和圆不拟合。
- 线帽保持 `0 J`。参考图的 1 px 圆帽小段不影响 coverage，没有改。
