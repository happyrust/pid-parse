# CPE-SQ 页角 0.169 mm：外框最后一个设备单位落在自己的裁剪框外（2026-11-07）

## 结论

七张 `CPE-SQ` 参考图（A0：I、J K、L M 井场；A1：一级闪蒸分离器 B、空冷器 A/B/C）
去掉图框掩膜后各剩 0.169 mm 未覆盖。这段不是模板里的哪条记录，而是出图器写外层
图幅框时，在折线末尾多走的一个设备单位。这一单位整段落在该路径自己的裁剪框外，
纸上印不出来。`read.rs` 以前不处理裁剪（`push_clip_path` 是空操作），所以把它读成
了参考墨迹。读取器改成按裁剪框截断墨迹之后，七张图整页未覆盖都从 0.169 降到
0.000 mm，coverage 1.000000。

A0 和 A1 读数一样，是因为两种出图的外框写法相同，与模板内容无关。

## 内容流

I井场（Producer Amyuni 4.5.2.9，页面 CTM 为单位矩阵），第一个裁剪块：

```text
q n 0 2383.68 3370.56 -2384.16 re W n
0.48 w
0 2383.68 m 3370.08 2383.68 l 3370.08 0 l 0 0 l 0 2383.68 l 0 2384.16 l
71.04 2355.36 m 3341.76 2355.36 l 3341.76 28.32 l 71.04 28.32 l 71.04 2355.36 l 71.04 2355.84 l
S Q
```

- 坐标都是 0.48 pt 的整数倍。设备分辨率是 150 dpi，一个设备单位为 0.48 pt，即 0.169 mm。
- 每条折线的最后一段都再往前多走一个单位：外框 `0 2383.68 l 0 2384.16 l`，内框
  `71.04 2355.36 l 71.04 2355.84 l`，会签栏横线 `71.04 1802.88 m 0 1802.88 l -0.48 1802.88 l`。
  2026-11-04 记下的虚线「主体 + 0.169 mm 笔帽」也是这一个单位
  （`2026-11-04-the-five-uncovered-remainders-are-dash-tips.md`）。
- 外框的裁剪框是 `x 0…3370.56, y −0.48…2383.68`，上沿正好是 `y 2383.68`。外框多走的
  那一单位从 `(0, 2383.68)` 到 `(0, 2384.16)`，整段在裁剪框外；其中一大半还在 MediaBox
  上沿 2383.933 之外。

A1 四张是同一种写法：`0 1683.36 m 2383.68 1683.36 l 2383.68 0 l 0 0 l 0 1683.36 l 0 1683.84 l`，
裁剪框上沿是 `y 1683.36`。

## 读取器为什么把它留下

外框四条边几乎和整页一样长，`sheet_edge_mm` 把它们丢掉，参考和我方都不计。外框只剩
页角这一个单位：它在 `(0.000, 840.909) → (0.000, 841.079)` mm，离我方最近的墨（内框的角）
有 10.1 mm，所以每张图记 0.169 mm 未覆盖。带掩膜比对时它在「左侧会签栏与左上角框」里，
所以不显示。

## 渲染核对

用 MuPDF 1.27.2 以 2880 dpi 渲染 I井场左上角 3 × 3 pt。原文件在 `y_top 0…0.253 pt`
（裁剪框上沿以上）的每一行都没有墨。把这一块的 `re W n` 去掉后再渲染，同一条带全黑。

## 落在裁剪框外的笔画

`probe_which_reference_ink_its_clip_hides` 用读取器同一个解释器，按读取器的方式维护裁剪栈，
列出被裁剪框截掉的每一段：

| 图 | 被截掉 | 其中整段 0.48 pt 的尾巴 |
|---|---:|---:|
| I / J K / L M 井场、一级闪蒸 B、空冷器 A/B/C | 2.879 mm | 17 段 |
| 一级闪蒸 A、低温分离器 A、换热器 CD | 0 | 0 |
| A2（轻烃分离器 I） | 420.116 mm | 1 段 |

七张 CPE-SQ 图的 17 段里，只有页角那一段没有被我方墨覆盖。其余 16 段在会签栏左沿
`x 0 → −0.169 mm`，原本就在 0.5 mm 覆盖半径以内。A2 被截掉的主要是整条右侧图幅边
（419.608 mm，`x 1684.32` 在裁剪框 `x ≤ 1683.84` 之外）和底边、左边各 0.169 mm，这些都是
sheet edge，读取器本来就丢掉；剩下的一段尾巴在右上角 `x 594.19 mm`，越出了页面。

文字：11 张图里没有一条 `Tj`/`TJ` 的起点落在裁剪框外，所以读取器只截断路径墨迹，不动字形。

## 改动

`read.rs` 的 `InkDevice` 维护一个裁剪栈，每层是该层裁剪路径的外接框与下一层取交集。
`push_segment` 只保留当前裁剪框内的那一段；只碰到框边、没有长度的一段不算墨。虚线相位和
sheet edge 判断仍按截断前的整段计算。非矩形裁剪按外接框截断：框外的墨肯定印不出来，
框内的墨有可能也被裁掉，读取器保守地保留。

我方写出的 PDF 没有 `W n`，也没有 Form XObject，所以我方读回的墨迹不变。

七张 CPE-SQ 图的参考总长各少 2.879 mm（17 × 0.169）。这 17 段尾巴以前会并进会签栏横线和
内框边，参与拟合；拿掉之后拟合比例略有变化（J K 由 1.0000735 变为 1.0000781，平移变化不到
4 µm）。J K 有三条贴边的笔画因此进入配对窗口，pen 一致数 13630 → 13633，其余十张不变。

`read_reference_plots` 的段数原来等于 PyMuPDF `get_drawings` 的 `l` 条数。PyMuPDF 不看裁剪，
所以新段数等于它的 `l` 条数减去整段在裁剪框外的 17 条：I井场 11 291 → 11 274，
一级闪蒸 B 1 662 → 1 645，其余三张不变。
