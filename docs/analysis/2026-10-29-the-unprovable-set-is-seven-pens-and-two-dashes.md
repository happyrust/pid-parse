# 不可证的 48 张，其实是 7 支笔、2 条虚线

> 日期：2026-10-29
> 性质：判据分解 + 新量具（`pid-plot/src/witness.rs`）
> 上游：`docs/plans/2026-10-29-plot-pdf-correctness.md` §5「下一层要缩小这个不可证集合」

## 1. 问题

上一轮把「正确」写成五条逐页判据，其中只有第 4 条有外部真值——和厂家自己的
出图 PDF 对比。53 张备份里只有 5 张有参考出图，于是另外 48 张只能写「未发现可
归属缺陷」。这是**逐页**判据的天花板，不是工作的天花板。

逐页判不了，可以**逐条目**判。一张页的墨由四种样式条目画出来：每根笔画的笔宽、
虚线节奏、每段文字的字面、以及它戴的图框模板。每个条目要么是某张**已验**页也
用到的——那么把它变成墨的那段机器已经和真图对过——要么不是，那就只有**它**待
证，页上其他墨仍然站在已验条目上。

这就是本单做的事：把「48 张页不可证」换成「这 7 支笔和这 2 条虚线从没出过图」，
短到能用手一条条结掉。

**「已验页」的定义只有一条：旁边放着它自己出图 PDF 的 `.pid`。** 之所以不能用
「看起来对的页」，是因为已验页会给自己的词汇作证——一张本身画错的页会把错的东
西认证成对的。先跑 `plot_compare_all`；哪张没过，就把它的 PDF 移出去再跑本量具。

## 4. 逐条结算

### 4.1 两条虚线：都不需要新参考图

- **`0.000`**（D04，10 根）：单段零长。`JStyleSimpleDashType` 记录里就是 `[-0.000]`，
  `write::dash_array` 明确把它当实线画（"a walk over that pattern is solid"），
  PDF 也不接受全零 dash array。已结。
- **`3.500/1.750`**（5 张，459 根）：记录里就是 `[-3.500/-1.750]`——和已见证的
  `[-1.905/-1.270]` 同形状（两段、同符号、同单位），走同一段读码和同一个
  `dash_array`。渲染器对 dash 没有任何查表，只有 `|mm| × PT_PER_MM`，所以「同一形
  状的新数字」不引入新风险。已结。

### 4.2 七个笔宽：只剩一个是真待证

笔宽过的是**三档笔表**（`pen_width_mm`：≤0.30 细 / ≤0.55 中 / 其余粗），这是从
参考图量出来的分档映射，所以未见证笔宽只有在**落在参考图没能夹住的档界区间内**
时才可能画错。五张参考页把两个档界夹到：

| 档界 | 见证夹出的区间 | 依据 |
|---|---|---|
| 细/中 | **(0.25, 0.35)** | 0.25 印细（204 处配对）；0.35 印中（2807 处配对） |
| 中/粗 | **(0.35, 0.70)** | 0.35 印中；0.70 印粗（515 段 0.68↔0.68 配对）。**此处原写作 (0.50, 0.70)，2026-10-30 撤回**：当年的 0.50 锚点是 `As Drawn` 占位值，参考在它们身上印的是细笔，见 `2026-10-30-as-drawn-is-not-a-pen.md` §7 |

于是：

- `0.7071` / `0.7500` / `0.7999` / `1.0606` / `1.1313` / `1.4141` —— 全部**高于
  0.70**，无论中/粗档界落在区间哪一点都是粗笔。**待证但结论唯一**，不需要新证据。
  （后四个还超过 `WIDEST_PEN_MM`，即"不是笔"；它们是模板自己的声明，1:1 画出，笔表
  把最粗的笔给它。）
- **`0.3000` 落在 (0.25, 0.35) 区间内部** —— 这是全项目**唯一**一个参考图说不清的
  条目：细笔和粗笔都和五张参考图完全一致。3 张页、24 根家具笔画。

`pid-plot/tests/style_witness.rs` 把这个数钉住（`(0, 24)`）：档界若收紧或放松，这
24 根会换笔，断言立刻说话。

### 4.3 字面与模板

- **字面 0 条**：53 张全部用五张参考页已有五个字面，一次嵌入都没走新路径。
- **模板 3 个文件**：`CPE-SQ-A2` 和两个 `CPECCHB`。模板不是独立风险——家具是那个
  文件 1:1 画出来的，几何的真值就是文件本身；模板相关的唯一待证项，就是它声明的
  笔宽，已经在上表里。

## 5. 新量具顺手找到的一件事：笔宽在参考页上并不完全一致

上面的分解只问「词汇有没有被见证」，不问「见证的那些画对了没有」。为了补上后一
半，新加了 `probe_pen_width_pairs`：它把**我方渲染页**和**参考页**的线段按位置配
对，再比宽度——`compare` 的覆盖率只管几何，从来看 `InkSegment::width_mm`。

```
14817 strokes agree, 318 differ, 2117 unpaired
   ours 0.17 ↔ ref 0.17   8044
   ours 0.34 ↔ ref 0.34   5836
   ours 0.68 ↔ ref 0.68    515
   ours 0.17 ↔ ref 0.34      0     ← 没有任何跨档错配
   ours 0.68 ↔ ref 0.34      0
   ours 0.34 ↔ ref 0.17    305     ← 唯一不同的一族
```

**没有任何跨档错配**（细↔中、中↔粗都是 0），所以三档映射本身是对的。305 段是
**五个符号族**，不是一族——`Circle.sym` 232、`Remarks.sym` 44、`Block.sym` 16、
`Item Note & Label.sym` 10、`Remarks Chinese_large.sym` 2（原稿写成「全是
`Remarks.sym`」，2026-10-30 更正）。逐页 158 / 44 / 51 / 61 / 4 段。

这是**规则之外还是规则之内**？把 `Ball Valve Type 2.sym` 的体（自己声明 0.13 mm）
放到模型里看：它被画成 0.35 mm，而参考在该处正是 0.339 —— 所以
`body_stroke`「放置的样式画整个体」这条规则**被参考图证实**，不能改。

那么差的就是这五个族**放置**解析出的笔：它们就差在命名同一条记录——随书叫
`As Drawn` 的占位样式（`I井场` 是 style 10 / 0.35 mm 黑；另外三张是 0.50 mm 蓝，
id 各不相同）。它不是一个笔宽声明，体的自备宽度（0.01–0.13 mm）站住，参考在那处
正是细笔。这条判据当天就落进 `body_stroke`，305 段里 304 段修好、0 段改坏：
15 135 段配对的一致/不一致由 14 817/318 变为 15 121/14。见
`2026-10-30-as-drawn-is-not-a-pen.md`。

顺带记一条方法：`probe_pen_width_pairs` 的配对必须允许**同一位置有多条参考线段**
（填充轮廓和描边是同一条多边形），否则会把我们的描边配对到对方的填充轮廓上，凭
空算出 363 段 0.34↔0.00 的差异（第一版正是如此）。

## 6. 现在的不可证集合

| 项 | 结论 |
|---|---|
| 53 张页的**图纸自己的墨** | 笔宽全部见证；两份虚线记录即数据；字面全部见证 ⇒ **无待证条目** |
| 两个 `CPECCHB` 模板的家具笔 | 6 个笔宽高于 0.70，任何档界都是粗笔 ⇒ **结论唯一，不是待证** |
| `0.3000 mm`（3 张、24 根家具笔画） | **待证**：细/中档界在 (0.25, 0.35) 内，参考图夹不住 |
| `0.5000 mm`（`D04` 24 根图内墨 + N/O/P 三张 12 根家具） | **待证（2026-10-30 新增）**：中/粗档界在 (0.35, 0.70) 内，0.50 落在里面；它此前「被见证」只因 `As Drawn` 的 0.50 顶替了它 |
| 五个 `As Drawn` 符号族的笔重 | **已结**：占位样式不声明笔，体的自备宽度站住；305 段里 304 段落地，0 段改坏 |
| 填充轮廓 | **已结（2026-10-30）**：参考给自己的 890 条填充轮廓描了 730 条（细 200 / 中 530），我方在这条边上本来就有 0.17 mm 的成员线；那 13 段差异是长度比拒配（0.29 对 0.61 弦），不是缺边，写图器不必改。见 `2026-10-30-a-fill-outline-is-not-a-pen.md` |
| 模板几何 | 家具是 `.igr` 的 1:1，真值即文件 |

所以「48 张不可证」收成了：**两个档界区间里的两个笔宽**。要再往
下收，只有一条：拿到戴 `CPECCHB-SQ-A1/A2` 的页的参考出图（一次能同时结掉 0.3000
与另外六个），或者拿到 `D04` 自己的出图（结掉 0.5000）。

### 6.1 这套分解**不管**几何

必须写清边界：上面拆的是「墨**怎么**画」——笔重、虚线节奏、字面、图框来源。它不管
墨**画在哪**。一张页可以把每一根线都放在错的位置、把每个符号缩错比例，而它用到的
词汇全部被见证，本分解照样判它干净。

「画在哪」只有参考出图能给：那是 `plot_compare` 的覆盖率与文字配对在五张上做的
事，也是 48 张页仍然拿不到的那一半。所以 `33` 张「干净页」的准确含义是**样式条目
全部有据**，不是「这张页正确」；`docs/plans/2026-10-29-plot-pdf-correctness.md` §1
第 4 条对它们仍然无法评估。本分解的价值在于：把不可证的那一半从「48 张页的每一根
线」压到「48 张页的每一根线的位置」，而样式这一半已经收口。

## 7. 量具
