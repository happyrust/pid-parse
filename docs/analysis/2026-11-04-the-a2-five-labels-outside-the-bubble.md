# A2 气泡外面的 5 条标签（2026-11-04）

11 月 2 日把未配对的 14 条参考标签都归给气泡上移 16.9 mm。验收 JSON 里 9 条是那一簇。另外 5 条的坐标不在 `x 492..514`。

## `动火点` 是一条记录

`probe_which_labels_reach_the_page` 对 `动火` 读出两条 `igTextBox`，各是整句 `动火点`：

| oid | 记录 | 纸面 |
|---|---|---|
| 33491 | `[0.290, 0.207]` m | `[290.189, 206.995]` mm，`Center` / `Middle`，字体 `Arial Narrow`，没有分栏 |
| 33499 | `[0.219, 0.263]` m | `[219.125, 262.806]` mm，同样 |

Arial Narrow 画不了这三个字。十一张图合用一套子集时，仿宋的子集里只有「点」，宋体的子集里有「动火点」。编码器按「第一个能画这个字的字体」切，于是「动火」进宋体、「点」进更靠前的仿宋，读回来是两段。单张图自己做子集时仿宋能画全句，不会切开。

命名字体一个字都画不了时，整句改交给能画全的那一款。`120℃` 不动：数字仍留在 Arial Narrow，只有 `℃` 另借一款。两款汉字的字宽都是 1 em，原点不因此挪动。

合成之后仍是一条。换到验收用的拟合坐标后，左端离参考原点 `(287.697, 205.740)` 与 `(216.577, 261.620)` 是 1.37 mm 和 1.30 mm，基线的 y 差在 0.07 mm 以内。都在 `TEXT_MM` 1.0 外面。不放宽 `TEXT_MM`。

## 参考的步进不是字宽字段

两条的字符样式是根 `StyleCluster` 的 id 67：字高正好 `0.0025` m，字体 `Arial Narrow`，段落 id 70 对齐是居中，行距 1。`+50..+68` 和段落上那五个间距 double 全是 0，和同页已经配上的宋体标签一样。没有字宽字段。

参考内容流不按 1 em 排这三个字。它换成 `NSimSun`，`Tf` 9.6 pt，`Tm` 是单位缩放，`Tc` 是 0，每个字单独一个 `Tm`：

```text
/F13 9.6 Tf
1 0 0 1 815.52 583.2 Tm <0004> Tj
1 0 0 1 819.84 583.2 Tm <0005> Tj
1 0 0 1 824.16 583.2 Tm <0006> Tj
```

`0004/0005/0006` 是「动」「火」「点」。步进 4.32 pt = 1.524 mm，正好是 9.6 pt 的 0.45。嵌入字体的 `hmtx` 仍是 256/256，墨宽约 0.89 em，所以这些字在参考页上是叠着的，不是压扁的。读回来的 `advance_mm` 6.435 mm 是两格步进加上最后一个字的整 em（18.24 pt），不是排字用的宽度。

拿插入点当中心、按 1.524 mm 一个字去算，左端会落到 287.90 和 216.84，离参考 0.21 mm 和 0.26 mm。仿宋 cap/em `171/256` 只是碰巧接近这个左端，内容流里没有这个比例。`Tm` 也不是横向缩放。

同页已配上的 `天然气自轻烃分离器I来` 是命名为仿宋的标签：em 3.725 mm（`Tf` 10.56 pt），11 字 advance 38.777 mm，约 0.95 em。十一张参考图里 `NSimSun` 一共 15 处，`Tf` 全是 9.6 pt；除了这两条 `动火点`，其余都是嵌在 Arial Narrow 句子里的单个字（`℃`）。没有第二个字高可以核对 0.45。

十一张验收图里，命名字体一个字都画不了、整句交给另一款的标签只有这两条。都是 2.5 mm、`Center`。没有第二个字高，也没有一条已经按 1 em 配上的居中回退。所以只在这一档乘 `1.524 / 2.5`：字形按这个步进压扁，居中和右对齐跟着这条宽度退。不把 `Tf` 改成 9.6，那一档按整 em 会把左端再向左推。`120℃` 不走这条路，数字仍留在 Arial Narrow。

按插入点居中之后，左端落到 287.90 和 216.84 附近，离参考 0.21 mm 和 0.26 mm。验收把这两条配上了。`min_text_matched` 从 211 收到 213。其余十张的配对数、覆盖率、多画、笔宽不符不变。

## `D` 不是半个字宽

`probe_symbol_label_offsets` 把 `SSV Sample Valve Type 2.sym` 的 `D` 配上了：锚点 `Left` / `Bottom`，转角 −90°，沿书写方向 −0.04 mm，横向 +0.88 mm。我方字高 3.17 mm，参考 4.44 mm。半个字高是 1.59 mm，符号锚点的一档是 0、0.5、1 或 1.32 个字高。+0.88 mm 对不上这些数。

验收里两边原点是 `(346.795, 275.675)` 与 `(345.794, 275.769)`，距离 1.005 mm，刚过 1.0。不改这档读法，不放宽 `TEXT_MM`。
