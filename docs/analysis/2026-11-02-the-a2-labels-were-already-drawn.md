# A2 的标签一直都在：`TICA` 与 `H=-15℃` 画了，错的是位置（2026-11-02 复核）

> 性质：对同日 `2026-11-02-the-a2-sheet-had-no-mask.md` §4–§5 的复核，
> 不是新发现。那份笔记把 A2 余下的 210.7 mm 归给「标签合成」并写「`H=-15℃`
> 一条都没画」；本轮逐层验证后，**这条归因不成立**，真正的位置差被量了出来。

## 0. 先说读数：一个都没动

`cargo test -p pid-plot --test reference_plots_acceptance` 全绿（2 tests，
109 s）。11 张参考图的 coverage / extra / 标签数 / pen 读数与 §4 记的完全一致，
复核当时 A2 是 `0.9819 / 210.712 mm / 标签 211 of 225`。2026-11-04 两条 `动火点` 配上后收到 213 of 225。本轮**不涉及阈值与钉子**，只改「为什么」。

## 1. 「`H=-15℃` 没画」是错的

`pid-plot/examples/probe_which_labels_reach_the_page.rs` 把一条标签拆成三段问：
`igTextBox` 解码 → `PidGraphicEntity` → `PaperShape::Text`。A2 那张图的答案：

| 标签 | 解码（`/Sheet6`） | 实体 | 纸面文字 |
|---|---|---|---|
| `TICA` | oid 865，4 字，`[0.501, 0.256]` m | `Sheet6:igtextbox:22`，`Labels` 层，`displayed=true` | **(500.836, 256.320) mm**，h 2.469 |
| `H=-15℃ ` | oid 34673，7 字，`[0.508, 0.261]` m | `Sheet6:igtextbox:192`，`Labels` 层，`displayed=true` | **(507.793, 260.766) mm**，h 2.469 |
| `L=-5℃ ` | oid 33992 | `Sheet6:igtextbox:156` | (508.307, 251.551) mm |
| `SP=-8℃` | oid 33263 | `Sheet6:igtextbox:104` | (508.245, 254.723) mm |

四个标签全部走完了三段，`TICA` 与 `H=-15℃` 都在纸面文字表里。UTF-16 也不是
分水岭：`H=-15`、`L=-5` 在 `.pid` 里只有 UTF-16 形态（字节 158 966 / 145 155），
`SP=-8` 另有 ASCII 副本（478 648 / 478 838），而三者在模型层一样正常。
原文「TICA 被合成成 TT」也不对：`TICA`（oid 865）与 `TT`（oid 523）是**两条
独立的 `igTextBox`**，都画了。

## 2. 表里这几条对不上，是因为整簇偏了

`plot/acceptance/*.json` 的 `unmatched_reference_text` / `unmatched_our_text`
把两边的原点都列了出来，差值干净得不像巧合：

| 参考页 | 我方 | Δy |
|---|---|---|
| `TT` (496.99, 221.83) | `TT` (498.89, 238.69) | **+16.86** |
| `0114301` (492.76, 216.58) | `0114301` (494.96, 233.38) | **+16.80** |
| `TICA` (495.47, 238.25) | `TICA` (497.34, 255.14) | **+16.89** |
| `0114301` (492.76, 233.00) | `0114301` (494.96, 249.83) | **+16.83** |
| `H=-15` (506.14, 240.62) | `H=-15` (507.65, 257.56) | **+16.94** |
| `L=-5` (506.65, 231.48) | `L=-5` (508.16, 248.35) | **+16.87** |
| `SP=-8℃` (506.14, 236.56) | `SP=-8℃` (508.10, 253.51) | **+16.95** |

`compare.rs` 的配对容差是 `TEXT_MM = 1.0`，所以这一簇 +16.9 mm 的 y 偏移足以让
表里这几条落榜，它们仍是气泡。当时簇外的 5 条里，两条 `动火点` 已配对，剩下 `D` 和两句管线文字，见
`docs/analysis/2026-11-04-the-a2-five-labels-outside-the-bubble.md`。

对照 `.pid` 自己的插入点可以看到偏移发生在哪一层：`TICA` 记录写的是
`(0.5008, 0.2563)` m，我方纸面就是 `256.32 mm`；参考页把它印在 `238.25 mm`。
即**记录 → 纸面这一段是忠实的**，差的是「这一簇应该在哪儿」。

## 3. 墨的读数指向同一处：同一个体、同一尺寸，整簇平移

`probe_which_extra_ink_the_reference_lacks`（本轮复跑，图名作参数）：

```
DCS Func Access in Prime Loc.sym   36 runs   98.388 mm
TT-Temperature Transmitter.sym     20 runs   24.574 mm
/Sheet6                            16 runs   79.143 mm
Flange Type 2.sym                   2 runs    6.666 mm
Remarks.sym                         3 runs    1.941 mm
```

`probe_which_extra_ink_the_reference_lacks -- "<图名>"` 把这一簇逐条印出来，
尺寸先对了：我们的外框并不小。

| | 参考页 | 我方 | 差 |
|---|---|---|---|
| 外框宽 | `(492.42,243.16)->(505.29,243.16)` = **12.869 mm** | 两竖 `x 494.34` / `x 507.04` = **12.698 mm** | 0.171 mm，= 笔宽 |
| 外框高 | 12.869（同尺寸） | `y 247.63..259.82` = 12.698 | 同上 |
| 外框位置 | 底边 `y 243.16` | 底边 `y 260.07` | **+16.91 mm** |
| 外框左右 | `x 492.42..505.29` | `x 494.34..507.04` | **+1.50…+2.18 mm** |
| 竖引线 | `x 498.69`，`y 243.16..342.39` = 99.229 mm | `x 500.69`，`y 287.62..342.69` = 55.569 mm | 远端重合，近端随气泡 |

外框两侧都差 0.169–0.171 mm，正好是这簇的笔宽，即**同一个体、同一尺寸**。
所以这一簇只错了一件：**整簇刚性平移 ≈(+1.9, +16.9) mm**。三条独立证据同向：
外框（+1.5…+2.2 / +16.91）、标签（+1.5…+2.2 / +16.86…+16.95）、`TT` 气球圆
（圆心 `(507.19,237.21)` 对参考 `(498.78,236.81)`）。

引线把方向钉死了：远端 `y≈342.4` 两边重合（我方 `342.69`、参考 `342.39`，
差 0.30 mm），近端却跟着气泡走（`287.62` 对 `243.16`）。这是一条**挂在工艺线
上的引线，气泡沿它被拖过**——`.pid` 记的是拖过之后的位置。

这也解释了读数卡在 0.9819：`extra` 的 98.4（`DCS Func Access`）+ 24.6
（`TT-Temperature Transmitter`）是「画在拖后位置的那一份」，`uncovered` 的
90.6 是「参考页在拖前位置的那一份」，同一簇被算了两次。`/Sheet6` 的 79.143 mm
后来逐条对过坐标，16 条都在 `x 500.69` 的这条引线上，不是页边框。
`Flange Type 2.sym` 的 6.666 mm 仍离参考墨 0.813 mm；`Remarks.sym` 的 1.941 mm
在拖后的气泡上，最近参考墨 9–10 mm。见
`docs/analysis/2026-11-04-the-a2-sheet6-extra-is-the-leader.md`。
未覆盖的 `/Sheet6` 120.511 mm 是这条引线在参考页的那一份、参考位置的 TT 气球，
加上虚线头。见
`docs/analysis/2026-11-04-the-a2-sheet6-uncovered-is-the-reference-leader.md`。

### 这不是渲染能补的

标签来自 `/Sheet6` 的 `igTextBox`，外框与气球来自符号体，两套**互不相干**的记录
给出同一个新位置——所以 `.pid` 自己就是这么存的，参考 PDF 记的是移动前的样子。
换句话说：同一张图的**数据版本不同**，不是我们画错。渲染器要么照数据画（现状），
要么改数据；没有第三条路。先前「体本身也不同、应查放置实例参数」的判断据此作废
（那是我把右半格 `7.619 mm` 误当成整个外框宽读出来的）。

## 4. A1 那 8.210 mm：八段 1.026 mm，一处装配

三张空冷器读数相同，本轮把 8.210 mm 逐段拆开，是 **8 段 1.026 mm**：

| 段 | 位置 | 最近参考墨 |
|---|---|---|
| ×4 | `y 363.5..367.4`，`x 663.5..665.7` | `x 664.63`，`y 354.25..370.50`（16.26 mm 竖线），距 0.71–0.75 mm |
| ×4 | `y 249.8..253.5`，`x 663.5..665.7` | `x 664.63`，`y 240.62..256.88`（16.26 mm 竖线），距 0.71–0.75 mm |

`probe_body_against_reference --window 660 352 668 372` 的并排结果已于同日复核，
本段原描述作废：竖杆**画了**，我方 `(664.67,370.61)->(664.67,354.52)` 对参考
`(664.63,370.50)->(664.63,354.41)`，差 0.06 mm、100% 落在参考墨上；引线与横管上的
记号也都对得上（最差 0.11 / 0.04 mm）。差的只有竖管上的那个**复合虚线记号**：
我方两条 3.59 mm 斜划落在距管段起点 5.08 mm（样式半个 advance），参考页落在 8.07 mm，
所以它只有 37% 盖住参考墨，8 条 1.026 mm 的 extra run 全在这两条斜划上。本轮已修：
单记号改为不早于段中点，三张 A1 的 extra 归零（见 §5）。
`uncovered` 归到 `Air Cooler Type 1.sym` / `Electric Motor Type 2.sym` 只是
`stroke_label_at` 就近贴的标签，那两处没有符号体参与。见
`docs/plans/2026-11-02-the-a1-stem.md`。

## 5. 结论与下一步

- A2 读数不变、钉子不动；A1 的 extra 归零，钉子随本轮收紧。
- A2 的 210.7 mm **不是**标签合成缺口。标签全部在，整簇偏了 (≈+1.9, +16.9) mm，
  外框尺寸一致（差一个笔宽），引线远端重合、近端随气泡。这是 `.pid` 与参考 PDF 的
  数据版本差：照数据画就是现在这样，要抬读数只能换参考或盖掩膜，改渲染没有用。
- A1 的 8.210 mm 也不是缺竖杆：竖杆、引线、横管记号三样都在 0.11 / 0.04 mm 以内对上，
  是竖管上 stamp 出来的复合虚线记号早到了 3 mm（我方 5.08，参考 8.07）。
  `probe_complex_dash_marks` 把参考页的记号中心量成 16.09 mm 管段 8.07 / 8.04、6.19 / 6.54 mm
  短管 5.09 / 5.14 / 5.02，于是单记号规则改为「半个 advance，但不早于段中点」，三张 A1 的
  extra 归零、coverage 抬到 0.9986 / 0.9987 / 0.9986。见 `docs/plans/2026-11-02-the-a1-stem.md`。
- 复核工具：`pid-plot/examples/probe_which_labels_reach_the_page.rs`（新增，
  逐层问「这条标签到纸面了吗」），配合既有的
  `probe_which_extra_ink_the_reference_lacks -- "<图名>"`（逐条 extra run 与最近参考墨）。
