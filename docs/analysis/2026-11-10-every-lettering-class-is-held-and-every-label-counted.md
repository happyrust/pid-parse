# 字符类阈值跳过的 6% 标签：真实偏差只有 `℃` 借字一处，其余是来源查找的口径（2026-11-10）

## 结论

`reference_plots_acceptance` 的两条字符类阈值（平均下移 ±0.04、平均宽差 ±0.02，单位是字高）
原先只管「不少于 10 条、且不是 `unknown`」的类。在 `b80b079` 上，掩膜视图配上的 3997 对里
它管住 3756 对，**241 对（6.03%）没有任何约束**；把同一对阈值套到被跳过的类上，超限的恰好
两个，都是 `unknown`：`低温分离器A`（5 对，宽差 +0.0237）与 `换热器CD`（4 对，+0.0294）。

查下来是两件事叠在一起：

1. **真实偏差只有一处**：以 `℃` 结尾的报警限标签（`L=35℃`、`H=120℃` 这一类，11 张图配上
   12 条）。样式点名的 Arial Narrow 画不了 `℃`，标签在两边都被切成两段。参考图的 `℃` 是
   NSimSun、`Tf 9.6`；我们借 FangSong，用标签自己的 10.17 pt，这一段比参考宽 **0.2011 mm**，
   按参考那一段的字高 3.387 mm 算是 **+0.0594 字高**，12 条逐条相同。
2. **其余是来源查找的口径**：一对 run 属于哪个类，要先找到它在纸面表里的那条标签
   （`compare.rs` 的 `find_source`）。原先只拿「我们第一段 run 的文字」去比，且只看标签的
   插入点离 run **起点**是否在 20 mm 以内。于是被切开的标签、右对齐或居中的长标签都找不到
   来源，一律进 `unknown`。两个超限的类就是「两段 `℃` + 两段拉丁字 + 0～1 条别的标签」平均
   出来的；另外六张有 `℃` 的图同样有这个偏差，只是被同类里别的标签稀释到阈值以内
   （`I井场` 的 `unknown` 是 +0.0191）。

这一轮不改排版（借字那一块等审查结论），改了三样：来源查找的口径、门禁不再跳过任何类、
逐条超限的标签数钉住。阈值一个没动。

改之后的数字可以复跑：`cargo run -p pid-plot --example
probe_which_label_a_paired_run_is_read_against` 逐张打印每一对「被切开的一段」与「找不到
标签」的 run 认到了哪条标签、逐条超限的标签、以及两个视图里每个类的读数（24 段、12 对、
64 条）；后来加上了两页字型不同的每一对（14 对，见第八节）。

## 四、来源查找改了什么（`pid-plot/src/compare.rs`）

1. **从标签自己的锚点量**。插入点离 run 的距离，按那条标签的对齐方式取 run 的起点、中点
   或末端来量（`Reach::distance_to`），不再一律从起点量。右对齐、居中的长标签因此找得到
   自己的标签；两条同字、首尾相接的居中标签也不再互相认错。
2. **按整条 run 链拼出的文字找**。我们把 `2"NC` 画成 `2"` + `NC` 两段时，标签是两段合起来
   拼出的那条；拼不出时再按第一段找（纸面表里本来就是两条标签、被参考印成一个 run 的情形，
   这一对是从第一条量起的）。
3. **被切开的一段，认它所在那一行拼出的标签**（`find_label_spelled_through`）。`℃` 这一段
   自己拼不出任何标签，它和前面的 `H=40` 首尾相接、合起来才是 `H=40℃`。类名写成
   `Left/Ascender part`：它按那条标签的规则落位，但宽度取决于自己那一段的字型，所以不并进
   整条标签的均值里——并进去的话，`低温分离器A` 的 `Left/Ascender` 会从 18 条变成 22 条，
   两个 `℃` 的 +0.0594 被平均到 +0.005 左右，门禁就看不见它了。

   只看「标签的文字里含有这一段」是不够的：`空冷器A` 上 `H=40℃` 的 `℃` 离下面一行
   `SP:30℃` 的插入点更近，按字符就近会认到另一条标签、另一个类上去。

改完之后，整页视图的 83 对 `unknown` 剩 12 对（就是上表最后一行），24 对进了
`Left/Ascender part`，47 对回到各自的规则类。11 页的覆盖率、多余墨、未覆盖、配对数、笔宽
等读数逐项不变（两次运行的读数文件逐字节相同）。

## 七、收紧方案

做了的（都不改排版，阈值一个没放宽）：

- 两条类阈值管**每一个**类：不再跳过不足 10 条的类，也不再跳过 `unknown`；掩膜视图之外，
  整页视图也查（模板标签的字距此前没有任何类阈值管）。
- `Left/Ascender part` 按阈值是超限的（+0.0294 对 0.02）。这是真实偏差，没有为它改阈值，
  而是把它钉在读数上：八张图各自不许比 +0.0294 更宽；哪一页回到阈值以内，门禁要求把那一页
  从名单里拿掉，免得钉值在偏差消失之后还留着。
- 逐条超限的标签数按页钉死（`WholePage::text_off`，合计 64）。多一条是有标签动了，少一条
  要求把钉值降下来。失败时逐条列出类、文字、锚点偏移与宽差。

没做的：

- 修 `℃` 借字的字号与字型（等借字那一块的审查结论）。修好之后 `Left/Ascender part` 应回到
  阈值以内，八页的钉值与 12 条逐条超限一起消掉。
- 剩下 12 对 `unknown`：我们的读回把纸面表里的两条标签粘成一个 run（参考是两个 run），
  或两边都是一个 run 而纸面表里是两条。可以按「run 的文字以哪条标签开头」归类，但那是又
  一条启发式规则，这 12 对的读数都在阈值以内，这一轮没有加。
- 逐条超限只钉了条数，没有钉每一条的读数。已经超限的标签偏得更远、而条数不变时，只有
  `℃` 那一类会被 `Left/Ascender part` 的钉值发现，模板那 44 条不会。
- `plot_compare.rs`（五张图的棘轮）里同样有「不足 10 条的类不查」这一条，没有动：那五张图
  都在验收门禁的 11 张里，按这里更严的规则查过。

## 八、后续：借来的 run 的字型族进了门禁（同日）

第三节那句「两边的字型与字号是普查从字形上读回来的」原先只是一次性的读数。现在读回函数
自己就给出每个 run 的字体名（`read::read_plot_with_faces`，取字体的 `BaseFont`、去掉子集
前缀），验收门禁按它多钉一个读数：标签点名的字型画不了的字，两页各自换别的字型写，配上对
的这种 run 我方与参考是不是同一个字型**族**。

| 图 | 借来的 run（配上对的） | 我方 | 参考 | 同族 |
|---|---|---|---|---|
| I井场 | `L=35℃`、`H=120℃` 的 `℃` | FangSong 3.588 mm | NSimSun 3.387 mm | 0 / 2 |
| L M井场 | `H=120℃`、`L=35℃` 的 `℃` | FangSong 3.588 mm | NSimSun 3.387 mm | 0 / 2 |
| 低温分离器A | `L=-19℃`、`H=-5℃` 的 `℃` | FangSong 3.588 mm | NSimSun 3.387 mm | 0 / 2 |
| 换热器CD | `L=-18℃`、`H=15℃` 的 `℃` | FangSong 3.588 mm | NSimSun 3.387 mm | 0 / 2 |

| **合计** | **14** | | | **2 / 14** |

字高是读回的字身高：3.387 mm 即 `Tf 9.6`，3.588 mm 即 10.17 pt。

- **哪些 run 算借来的**：从写出的 PDF 读回每个 run 的字体名，与这条标签点名的字型（样式的
  字型加标签内各 run 点名的字型，`fonts::typeface_key`）比，族不在其中的就是借来的。写出器
  「借谁」的规则在这里一个字都不重复。
- **族**：测试里的明文表 `FAMILIES`。宋体与新宋体是一族（NSimSun 就是拉丁字等宽的 SimSun），
  仿宋一族，Arial、Arial Narrow 各一族；同一个字型在两页上的写法都列出来（参考的驱动写
  `ArialNarrow`，我方写字库自己的族名 `Arial Narrow`）。读到表里没有的名字，那一页直接
  失败。
- **钉法**：每页借来的 run 数精确钉（`WholePage::borrowed`），同族数只许升
  （`borrowed_in_family`）：少了是有 run 离开了参考的族，多了要求把钉值提上去。
- **管不到的**：A2 图被拖动的仪表簇里还有两条借来的 `℃`（`L=-5℃`、`H=-15℃`）与参考配不上
  对，没有参考 run 可比，不在读数里。按文字到参考图里找同一条，也是 NSimSun 对 FangSong，
  所以按「标签」数是 16 条里 2 条同族。
- **另一个角度的核对**：`probe_which_label_a_paired_run_is_read_against` 现在逐对比两页的
  字体名，11 页全部配上的对里字型不同的恰好是这 14 对，没有第 15 对——配上对的 run 里，除了
  借字，两页的字型处处相同。
- **变异**：把有汉字的标签改成先借 FangSong，门禁在 A2 页失败（`0 borrowed runs are in the
  reference's font family where 2 are pinned; one has left it`），这道门原有的各项读数都
  拦不住它（库内用例拦得住）；把 `NSimSun` 从表里拿掉，门禁在第一页失败并点名这个字体名。
