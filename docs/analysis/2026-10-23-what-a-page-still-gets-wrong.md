# PDF 导出还剩什么：一张页的结构全过，差的是一整套图框家具（2026-10-23 全量体检）

把整台机器上能出图的东西全导一遍：`pid-test-data` 的整厂备份 53 张、`test-file/` 的 5 张、
语料 `I井场`（与备份重复）—— **59 次导出、58 张唯一图**。每张都走
`lay_out_drawing` → `prepare_fonts` → `write_plot` → 读回，再用 MuPDF 1.27 与
Poppler 25.07 两套独立读取器各开一次。结构层没有一处失败；这份体检真正改掉的只有一处
非法 PDF 状态，而剩下最大的一处差**不在几何里，在图纸家具里**。

## 一、修掉的一处：零长虚线写成了非法 dash 数组

`D04` 的 10 条描边带着一个只声明一段 `0.0 mm` 的 dash 模式。`paint_primitive` 原来的
判据是「`dash_mm` 非空就写 `d`」，于是这 10 条在页面里落成 **`[0] 0 d`** ——
PDF 8.4.3.6 要求 dash 数组的数非负、**且不能全为 0**。MuPDF 把它当实线（模型侧本来就
是实线：`DashWalk` 的周期为 0 时直接返回整段），严格的读取器可能拒画或报错。

`write::dash_array` 现在按同一口径归一：空模式、全零模式、含非有限值的模式都不写 dash
状态，页面用该笔的实线画。读数：

| | 改前 | 改后 |
|---|---:|---:|
| D04 内容流里的 `[0] 0 d` | 10 | **0** |
| D04 内容流里的 `[3.5 1.75] 0 d` | 18 | 18 |
| D04 字节数 | 179 241 | 179 220 |
| 其余 58 页字节 | — | 逐位不变（只有 D04 有这个模式） |

单测 `a_zero_length_dash_pattern_is_written_solid` 把「零长虚线 = 实线」钉在生成字节上：
两种模式写出的 PDF 必须逐字节相同，真虚线（`[3.5, 1.75]`）必须不同。

## 二、最大的一处没画：图框、标题栏、会签栏

`plot_compare` 用 `pid-plot/assets/template-masks.json` 把「左侧会签栏」与「右下标题栏」
两块矩形整块 mask 掉。所以「五张参考图的文字 546/546、151/151、123/123、167/167、249/249」
量的是**遮罩外**的字，这两块从未进过判据。把两块矩形里的 span 单独取出来比：

| 图 | 遮罩区内参考 span | 我方 span | 参考有、我方没有的字符串 |
|---|---:|---:|---:|
| I井场 | 37 | 3 | **30** |
| 一级闪蒸分离器B | 38 | 4 | **30** |
| 一级闪蒸分离器A | 4 | 4 | 0 |
| 换热器CD | 4 | 4 | 0 |
| 低温分离器A | 4 | 3 | 1（`DD11008-`） |

I 与 B 缺的是整张标题栏加会签栏：`中国石油集团工程设计有限责任公司华北分公司`、
`会 签 专 业`、`修改号`、`制  图`、`勘察证书号`、`CADD号`、`A111001641`、
`CPENC-DD11008`、`2012,05,15`、`1 版`、`010065-kj` 等 30 条，加上参考那两道
**8 009.1 mm / 8 304.0 mm** 的双线图框（`2026-10-20-the-page-frame-is-the-print-drivers-quad.md`
的读数）。A、低温 A、换热器 CD 三张的参考本来就没有这两块（矢量和像素两路都是 0），
所以在它们上面「没画」不是差。

**不是读漏**：这些字符串在 `.pid` 里 0 次（按 GBK / UTF-16LE / UTF-8 都搜过
`勘察证书号`、`会签专业`、公司名、图号）。它们住在 `igSmartFrame2d` 指向的**链接 OLE
图框模板**里 —— 语料是 `Ref/Template Files/CPE-SQ-A0.igr` 与 `CPE-SQ-A1.igr`，
`.pid` 只存 `CPE-SQ~3.IGR` 这样的短路径。解析器已经把 `0x003D` 读成
Linked / Embedded / LocallyLinked 三态（`2026-07-27-smartframe-003d-native-reader.md`），
但只拿它当页幅记录，**没有去开那个文件**；`2026-10-20-the-page-frame-is-the-print-drivers-quad.md`
也把「画框」明确列在当时范围之外。

这就是剩下最大的一处可见差：两张参考有完整图纸家具，我们一张没有，而对比器两侧都被
mask 排掉，分数上看不见。要做的话是读 `.igr`（同一套 IGDS 记录 + 文字），按记录里的
`+76/+84` 页幅落到纸上；`AGENTS.md` 已记着 `.igr` 模板里的 `igArc2d` 会被读出来
（logo 字形与圆角），所以解码层不是从零开始，缺的是「找到模板 → 把它的实体并进模型」。

> **2026-10-23 已做**：这一节同一天落地。模板按「描边范围等于页幅」认（误差 ≤ 2 mm），
> 173 条图元 1:1 并进 `PaperModel` 排在内容之前；两条框落在 (0,0)–(841,594) 与
> (25,10)–(831,584)，参考是 (0,0.15)–(840.91,594) 与 (25.06,10.14)–(830.92,584.01)；
> 遮罩区文字 `B` 4 → **38**（模板 34 + 图纸 4）、`I` 1 → **35**。`A` 与 `低温A` 的参考本来
> 没有家具，同样的墨因此各 +15 mm 多画（基线从 10 / 26 抬到 25 / 40）。
> 见 `2026-10-23-the-border-template-draws-the-sheet-furniture.md`。

## 三、量到但本轮不动的几处

- **两条方向不明的弧**（FT-Ultrasonic 的波形、Local Vent 的顶盖）：
  `2026-10-20-what-the-last-98-mm-of-extra-ink-is.md` §4 已经定案「方向在记录里读不出来」——
  24 条有方向的弧 24 条符合现行约定，任何单条规则都会先破掉 Manifold 或 Cap。今天仍是
  I 图最大的两堆残差：FT-Ultrasonic 漏画 10.34 / 多画 10.48 mm，Local Vent 7.28 / 5.79 mm。
  本轮量到两条波形弧的方向分布：**上弧参考在左半、下弧在右半**，我方两条都画右半；
  与 §4 的「合成一个波形」结论一致，没有新证据能把它读出来。
- **D04 的 23 条重复图元**：同一 `(stroke, shape)` 出现在多条记录上，其中 3 条虚线就是
  §1 那个零长模式；其余是符号体里逐条重复的实线，重合之后纸上不变。
- **B井场 4 条同位同字标签**：`苏4-9注采井`、`苏4-10注采井` 各出现两次，两个不同的
  `Sheet6` 字节区间写着同一条字、落在同一个插入点 —— 源图的重复记录，不是布局重复。
- **N井场 一条标签出页 1.55 mm**：`15-TD-4101416-B2-EH40`（竖排、`Ascender`）的插入点
  y = −1.55 mm，字首被页底裁掉。页幅是图纸声明的 843.46 × 596.71，`beyond_the_sheet`
  只拒「整条在页外」与「跨度超过四倍对角线」，所以它照画，裁切交给 PDF 页面。要改得先定
  「出页的文字算不算该拒」，本轮不猜。
- **Q井场 的 10 mm 橙色高亮**：`2 Way Globe Type 3.sym` 体里 9 条描边声明 10 mm、色
  `(255,167,119)`；单色三笔表把 10 mm 折成最粗的 0.678 mm，于是这个 3.3 mm 的小三角
  比邻居重一档。该图不在五张参考里，无法判断厂商是否画高亮，记录在案。
- **4 张没声明页幅**：D井场 / Q井场 / 换热器CD / 凝析油一级闪蒸B气相出口改造，按内容落回
  A0 / A1 ×2 / A2（`resolved_page`）；出页后逐张用 `pdfinfo` 核过，是整 A 幅。
- **字体没有 subset 前缀**：`pdffonts` 报 `sub no`（数据已子集化，只是名字没带 `ABCDEF+`）。
  PDF 不强制，只是「这是子集」的提示缺失。
- **48 张备份没有参考出图**：只有结构与审计（页幅、图元普查、符号覆盖、读回段数），
  没有像素级对照。它们身上任何一处像 §2 那样的差都还没有对照物。

## 四、逐页体检口径

新探针 `pid-plot/examples/probe_page_defects`（单文件或整目录）：

```text
cargo run -p pid-plot --example probe_page_defects -- <a.pid|dir> [more ...]
```

每张图报：重复图元（同一笔与同一 pen 出现两次以上）、退化图元（零长线、零半径弧/圆、
不足两个点的链、不足三个点的填充）、非有限坐标（writer 会静默丢掉）、文字高度区间、
同位同字标签、run 分区覆盖问题、笔宽分布、虚线模式、缺符号数、墨迹到页边的四边距。

59 次导出的读数：

- **0 失败**、0 非有限坐标、0 退化图元、0 被拒笔画（`off_sheet_primitives`）、
  0 占位框（`missing_boxes`）；每页 1 个 page；
- 文字高度 1.5–5.08 mm；字体只有 `Arial` / `Arial Narrow` / `仿宋` / `宋体`；
- 墨迹越出页面的只有 N井场那一条标签（§3）；
- 两套独立读取器（MuPDF 1.27、Poppler 25.07）逐页打开、抽字都成功；
- 内容流里没有 `nan` / `inf`，没有全零 dash 数组；
- 五张参考图：覆盖率 0.9989 / 0.9998 / 0.9979 / 0.9986 / 0.9993，多画 42 / 8 / 2 / 23 / 25 mm，
  文字 546/546、151/151、123/123、167/167、249/249，逐位与改前相同。

符号库缺口的账没变：`test-file` 那三张 `XA …` 全仓库 0 命中；备份侧三条文件名
（`Pulsation Damper.sym`、裸名 `Wellhead Christmas Tree.sym`、一个改名的温度变送器）
共 18 处放置，全部用图内缓存体画出，占位框仍是 0。

## 结论

按「可见提升」排序：先做 §2 的 `.igr` 图纸家具（两张参考有、我们一张没有，且它被 mask
挡住所以分数上看不见）；§3 的那两条弧要等一份能确定方向的新证据（带这两件符号的 `.igr`
或另一张参考图）；其余都是测量口径、源图重复或记录在案的例外。
