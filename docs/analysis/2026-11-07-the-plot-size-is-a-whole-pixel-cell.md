# 出图字号：字高换成整像素的字体单元格

日期：2026-11-07

## 结论

参考图的 `Tf` 不是按字号逐条凑出来的，而是一条规则：出图器按 GDI 的方式在 150 dpi 下定字号。

1. 样式字高是字体的某一种高度。大写高样式（`0x0D`）取 `OS/2 sCapHeight`，ascent 样式（`0x0C`）取 `usWinAscent`。由此得到 em = 字高 ÷ 该高度占 em 的比例。
2. 字体按**单元格高**（`usWinAscent + usWinDescent`）请求，单元格高在 150 dpi 下四舍五入成整像素。
3. 写出的 `Tf` 是这个整像素单元格对应的 em，再取到出图坐标网格 1/2400 in（0.03 pt）。

`write::plotted_size_pt` 改成这条规则，`measured_tf` 那张 16 行的表删掉。

11 张图的 coverage、extra、文字配对数、pen 读数都没有变化。

## 没有完全落到字体表上的一处：Arial Narrow 的大写高

`ARIALN.TTF` 是 `OS/2` version 1，没有 `sCapHeight`。用 `H` 顶 1466/2048 = 0.716 算，7 pt 和 10 pt 都少 1 px（9.75 / 13.98）。参考的 24 px、34 px 把比值限定在 0.685…0.702 之间。代码用命名常量 `UNSTATED_CAP_EM = 0.7` 表示「字体没写大写高时出图器取的值」。这个 0.7 是落在区间内的取值，不是从厂商代码读出来的。厂商回退值的具体来源已交给 IDA 核对。

## 剩余的字号差异（与本条无关）

- 参考的部分文字 `Tm` 带 1.008 / 1.012 的等比缩放，例如 `12.45 × 1.012 = 12.60`、`10.17 × 1.008 = 10.25`，所以读回高度大约高 1%。我们没有这一层。
- A2 `CPECC`（模板 SimSun 1.0 mm，w1000）：规则给 4.32 pt，参考 12.96 pt，属于清单里的 CPECC 字高问题。
- `动火点` 在参考里借 NSimSun 9.6 pt 排字，我们整串借字体，字距不变（1.524 mm）。
