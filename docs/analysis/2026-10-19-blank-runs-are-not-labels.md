# 2026-10-19 — 空白文本 run 不是标签

范围：`pid-plot/src/compare.rs::match_text`，以及五张图对比的文字数字。上一轮
把符号体标签的竖直锚点改成中线读法之后，I 图的残差表里还剩 15 条「参考有、
我方没有」，其中 6 条 `text` 是空串。这些不是没画出来的标签：参考图和我们的
图里都有纯空格的文本 run（一个空格字模），它们既配不上任何东西，也不该被
当作「漏掉的标签」占据残差表。

## 之前统计的是什么

`match_text` 把参考图的每个 span 都算进 `text_reference`，我方每个 span 都算
进 `text_ours`，配对条件是「规范化后的字符串相等」且两点相距 ≤ 1 mm。规范化
把连续空白压成一个空格，纯空格就压成空串 —— 于是两个空串可以「相等」，两条
空白 run 互相配对，记成一次 `text_matched`。

I 图的报告：`text_reference 552 / matched 537 / unmatched 15`，其中 6 条空串；
我方 `unmatched` 13 条里有 2 条空串。也就是说，残差表 15 条里有 6 条从一开始
就没有可配的对象，而有些图里空串之间还凑成了「匹配」。

## 改成什么

`match_text` 在两侧都先规范化，规范化后为空就直接跳过：不计入分母、不计入
`matched`、不进入残差表。`text_sources` 早就是这样做的（`value.is_empty()`
时返回 `None`），这里是补上同一规则。

新增单测 `a_whitespace_only_run_is_not_a_label`：两侧各放一条纯空格 run 和一条
真实文字，断言 `text_reference == text_ours == text_matched == 1`，两张残差表
都为空。

`matched` 掉了 4 条，就是四对空串互相配对的幽灵匹配；参考总数掉了 14 条，

`tests/plot_compare.rs` 的 `min_text_matched` 因此重锁为 537 / 143 / 119 /
165 / 249。覆盖率、多画毫米、fit 一个数没动。

## I 图剩下的 9 条参考残差

新口径下剩下的都是真东西，九条分六类：

- **`Electric Motor Type 1.sym` 的两个 `M`**（2 条）：我方 2.04 mm，参考
  4.55 mm。符号体 `.sym` 里这条文字自己的字符样式是 2.54 mm，图纸把这个
  符号放在 **0.804** 的缩放上（`igSymbol2d` 的 `scale` 两个分量都是
  0.8041），2.54 × 0.804 = 2.04，与实际出图一致。参考图的 4.55 mm 既不是
  2.54 也不是 2.54 × 0.804，无法由已读到的字段解释；见
  `2026-10-19-symbol-label-nibble-hangs-from-the-middle.md` 末节。
- **`2"NC` 两处**（2 条）：参考记成一个 run，我方拆成 `2"` 与 `NC` 两条；
  两条 `2"` 都旋转 +90°，`NC` 在沿行向 +3.4 mm 处接着排。
- **`NC` / `2"` 各一处**（767.8 / 768.1 mm 附近，2 条）：这里反过来 ——
  我方一条 `2"NC`，参考拆成两个 run。
- **`B2B5` 一处**：参考一个 run，我方 `B2` 与 `B5` 两条。
- **`L=200mm` 一处**：差 1.24 mm（沿行 −0.99、降部 +0.75），刚出 1 mm
  匹配窗；我方这条是 `Right` / `Top` 锚点、插入点 (252.45, 407.80)，参考
  基线在 404.54，差的不是切分也不是字高，而是插入点本身。
- **`DWG-0000集05-07` 一处**：我方 x=1075.29、参考 x=1092.88，差 17.6 mm，
  是标题栏里真实的位置差，值得单独查。

切分类（上面第 2–4 类，共 5 条）说明下一步该做的是「同一行相邻 run 合并
后再配对」，那是配对器的另一件事，本轮没有动它 —— 合并会同时改变每个数字
的口径，应该单独一轮。**已做**：见
`2026-10-19-split-labels-pair-across-runs.md`，计数单位保持不变，这 5 条全部
对上。
