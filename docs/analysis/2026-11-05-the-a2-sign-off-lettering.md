# A2 会签栏的宋体标签：字号与基线（2026-11-05）

改正后的 `probe_symbol_label_offsets`（右 / 中对齐扣掉参考字宽）在 A2 上读出一组整齐的偏差：
`hqz.sym` 与 `A$C40D91A4B.sym` 的 12 条居中标签（`会 签 专 业` / `签 署` / `日 期`，
`修改` / `审核` / `页次` …）沿竖直书写方向的横向全部是 +0.28 / +0.30 个参考字高，
即 1.48 / 1.86 mm。

## 两件事叠在一起

**字号。** 这两个符号的字高是 2.5 / 3.0 mm，放置比例 1.4141，落到纸上 3.54 / 4.24 mm，
`plotted_size_pt` 给 10.02 / 12.03 pt。参考 `Tf` 读出来是 5.25 / 6.27 mm，即 14.88 / 17.76 pt，
比纸上字高大 1.48 倍。这与 `SimSun` 表里已有的几行（7.09 → 10.56、9.92 → 14.40，约 1.49）同一比例；
只是 10.02 / 12.03 pt 这两档以前没量过，落回了样式点数。表里补上这两行。

**基线。** 半字节读法里，符号体的低半字节 `0` 一直按「中线」处理，依据是 10 月 19 日阀门里的
`M`（`docs/analysis/2026-10-19-symbol-label-nibble-hangs-from-the-middle.md` 写的是 `0x10`）。
把全语料（53 张备份 + `test-file`）的符号标签按锚点码数一遍：阀门的 `M` 实际是 **`0x13`**，
`0x10` 只出现在会签栏这 21 条宋体标签上。补上字号以后，中线读法把它们放低 0.29 个字高；
按基线读，残差是 −0.04 / −0.05，与图纸 `igTextBox` 的 `0 → 基线` 一致。

## 改法

- `write::measured_tf`：`("SimSun", 1002, 14.88)`、`("SimSun", 1203, 17.76)`。
- `TextLine::from_symbol_anchor_code`：低半字节恰为 `0` → `Bottom`；`% 3 == 1` 仍是升部线；
  其余（含 `3`）中线。单测改为钉 `0x10 / 0x11 / 0x12 / 0x13 / 0x15 / 0x18`。
