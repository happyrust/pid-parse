## 3. 三个开区间

`probe_pen_width_pairs` 改为走语料目录里每一对同名 `.pid`/`.pdf`，声明值按
图纸墨 / 符号体 / 家具分列（`target-gates/pen-pairs-11.log`）。直笔、且参考在
该处只声明一个宽度的，十一张合计：

| 声明 | 印出 | 来源 | 根数 |
|---|---|---|---:|
| 0.01 / 0.13 / 0.18 / 0.25 | 0.17 细 | 符号体、图纸墨、家具 | 与 `≤ 0.30` 一致 |
| 0.35 | 0.34 中 | 符号体 9665 | 与 `≤ 0.55` 一致 |

没有一行声明宽度印成了 `pen_width_mm` 不会给的那支笔。页级笔表有 3 条不符
（`J K` 2 条、`L M` 1 条，都是我方 0.34 对参考 0.17），是验收门已经钉住的上限，
不是新的跨档。A2 页 `1.02` 对 `1.02` 共 17 条，`differed` 为 0。直笔表没有点名
`0.70` 与 `1.06` 之间的声明，所以厚/宽下界**不收紧**，仍是 `(0.70, 1.06)`。

于是未见证、又落在开区间里的宽度从两个变成四个：

| 档界 | 区间 | 落在里面、且十一张都没声明的 |
|---|---|---|
| 细/中 | `(0.25, 0.35)` | `0.3000` |
| 中/粗 | `(0.35, 0.70)` | `0.5000` |
| 厚/宽 | `(0.70, 1.06)` | `0.7500`、`0.7999` |

`0.7071` 落在厚/宽区间里，但 A2 验收页声明了它，该页笔列全一致，折算又把它送进
粗笔，所以它是已见证，不进这张表。
