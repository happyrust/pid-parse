# 标记与它压着的墨：先后是图纸的表定的，没有另外的规则

2026-11-12。墨迹门禁在 `一级闪蒸分离器A` 上钉着两行「未定」：标签 `P`（全文 `P70`）在 (339.85, 384.39) mm 的
原点标记，参考图先画标记后写字，我方先写字。这一篇查这个先后有没有规则。

## 结论

- **没有「标记在前」或「文字在前」的规则。** 11 张参考图上，纸色笔画压在墨上的地方共 91 处，两侧都在我方模型里的
  90 处：参考图先画墨的 60 处、先画标记的 30 处。带原点标记的标签共 96 条：图纸把文字列在符号之后的 49 条、
  之前的 47 条。
- **先后是图纸的表定的。** 90 处里图纸的表与参考图同序的 89 处；96 条标签里参考图按表画的 95 条——49 条先标记
  后文字、46 条先文字后标记。
- **那一条例外在记录上无从解释。** `一级闪蒸分离器A` 的 `P70`：表把文字列在符号前面（文字的拥有者在第 99 位，
  符号在第 104 位），参考图却先画标记、紧接着写字。`一级闪蒸分离器B` 上有**同一条标签**——同一个符号、同一段
  文字、同一个位置、表里同样的 99 与 104——它的参考图先写字后画标记，按表。两张图上的记录只差各自文档内部的
  编号（oid、样式号、缓存体的引用，见第四节），位置相同，两张图两种画法：没有哪条只看记录的规则能同时给出
  这两个结果。
- 所以我方不改画法，门禁那两行留着，说明里写上这些读数；统计由门禁的一条新用例钉住。

## 一、标记与文字是两条记录

标签在图纸上是两样东西：

- 符号：一条 `igSymbol2d` 记录，图纸的表把它列在自己的位置上。`Remarks.sym` 这类标签符号的本体里有一道原点
  标记，出图时用纸色画。
- 文字：一条 `igTextBox` 记录，它的拥有者是一个 `DependencyObject`（`0x00FA`），那个对象的载荷在 `+16` 写着符号
  的 oid。表把这个对象列在另一个位置上。

所以「标签与它的原点标记谁先画」在表里有答案：符号的位置对文字拥有者的位置。96 条标签里拥有者要么紧跟在符号
后面一位（49 条），要么在符号前面（47 条），没有第三种。

（探针第一版拿「同一条记录」当「同一条标签」，读出来 0 处——文字从来不是符号那条记录。照上面的关系读，55 处是
标记压在自己标签的文字上，35 处压在别的东西上。）

## 二、量了什么

`pid-plot/examples/probe_which_of_a_mark_and_its_ink_a_plot_paints_first`，对语料里每张带参考图的图纸：

1. **位置**：`pid_plot::ink::wipe_sites`（墨迹门禁 `wipe_order` 的逐项版本）给出参考图上每一处「纸色笔画压在墨上」
   ——墨是一个字还是一道笔画，参考图先画哪个，我方先画哪个。探针再从我方的页面模型里找出标记与墨各自出自
   哪条记录、表给它们的位置，以及墨是不是标记自己标签的文字。
2. **标签**：`pid-plot/tests/support/marked_labels.rs` 读每一条符号带标记的标签，不管标记压没压在墨上：表里符号
   与文字的位置；参考图上纸色笔画过标记那一点的步号，与拼出这段文字的那串字的第一个字的步号。

## 四、那一条例外与它的孪生

| | `一级闪蒸分离器A` | `一级闪蒸分离器B` |
|---|---|---|
| 符号 | `Remarks.sym`，`/Sheet6 +252`，oid 26，表里第 104 位 | `Remarks.sym`，`/Sheet6 +37586`，oid 1225，第 104 位 |
| 文字 | `P70`，`+40812`，拥有者 `+39189`（`0x00FA`，oid 2370），第 99 位 | `P70`，`+5650`，拥有者 `+35466`（oid 1139），第 99 位 |
| 拥有者载荷 `+16` | 26（就是那个符号） | 1225（就是那个符号） |
| 标记在页面上 | (340.58, 385.75) | (340.58, 385.75) |
| 参考图 | 标记第 589 步，`P` 第 590 步：先标记，紧接着文字 | `P` 第 411 步，标记第 438 步：先文字，按表 |
| 表前后十位（97–106）的记录类型 | `fa fa fa fa fa fa fa ce fa ce` | 同左 |

两张图上这条标签的三条记录长度相同（符号 113 字节、拥有者 98、文字 74），**只有文档内部的编号不同**，表里的
位置相同。逐字节比，三条记录共 20 个字节不同，每一个都是某个编号的一部分
（`tools/display_order/label_records_apart.py`，A / B）：

| 记录 | 不同的地方（载荷偏移） | 是什么 |
|---|---|---|
| 符号 `igSymbol2d` | `+0`（26 / 1225） | 自己的 oid |
| | `+25`（46 / 63） | 符号体用的样式号（文档自己的 `StyleCluster` 里的编号） |
| | `+29`（85 / 94） | 点名 `.sym` 路径的那个站点的 id |
| | `+105`（315 / 354）、`+109`（3773 / 2895） | 缓存体的两个引用：定义图纸在缓存里的编号、缓存站点的 id |
| 拥有者 `DependencyObject` | `+0`（2370 / 1139）、`+16`（26 / 1225）、`+34`（2438 / 255） | 自己的、符号的、文字的 oid |
| | `+22`（2794 / 2723） | 另一个对象的 oid（`/Sheet6` 里没有活记录带这个 oid） |
| 文字 `igTextBox` | `+0`（2438 / 255）、`+4`（2370 / 1139） | 自己的、拥有者的 oid |
| | `+14`（36 / 58）、`+26`（34 / 56） | 段落样式号、它那一段字的字符样式号 |

其余字节——类型字、所在的层、变换与插入点、文字 `P70`、文字的位置——逐字节相同；两张图里都没有这三条记录的

id 与缓存体的引用，文字记录里的两个样式号也不同。第十一次独立审查指出，这里是逐字节重读之后的说法；结论不变。）

B 的参考图按表画，A 的不按。A 的参考图上三条

## 六、能说到哪一步

**成立的**：先后由表定（95 / 96、89 / 90）；例外那一条的记录与孪生图上的只差文档内部的编号、表里的位置相同，
而画法相反，所以不是我方漏读了什么规则；A 的参考图整体上就不是按手头这份表画的。

**分不开的**：A 的图纸在 7 月到 10 月之间改过（表变了），还是那张参考图是用别的办法出的。两者手头的数据都
不排除，门禁里那两行因此仍记「未定」，与同一张图上边框那四行一样；我没有把它们改成「等现场数据」。要定下来，
需要现场给出那张参考图出图时的图纸。

**没有做的**：没有去找 A 的参考图整体按什么次序画。

## 七、门禁里钉了什么

`pid-plot/tests/reference_plots_ink.rs::a_label_and_its_origin_mark_are_painted_in_the_order_the_sheet_lists_them`
（只读参考图与图纸，不写页面，不要字体；语料不在时说一声后通过）：

- 每张图四个数（`MARKED_LABELS`）：标签数、表里文字在前的、参考图文字在前的、按表画的；
- 每条标签：拥有者要么紧跟符号要么在前；按表画的，「文字紧跟标记」当且仅当「拥有者紧跟符号」；
- 恰好一条不按表（`AGAINST_ITS_LIST`：图名、文字、符号、两个位置），而且它是「标记之后紧接着文字」；
- 它的孪生（`ITS_TWIN`）：同文字、同符号、同位置（0.01 mm 内）、同两个表位，按表画、文字在前。
