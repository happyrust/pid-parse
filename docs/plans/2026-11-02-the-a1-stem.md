# A1 的 8.210 mm：不是缺竖杆，是一个虚线记号晚到 3 mm（2026-11-02）

> 接 `docs/analysis/2026-11-02-the-a2-labels-were-already-drawn.md` §4 的「下一步」。
> 三条 A1（空冷器 A/B/C）读数完全相同：`coverage 0.9981 / extra 8.210 mm`，
> 8 条 extra run 每条 1.026 mm，最近参考墨是 `x 664.63` 的 16.26 mm 竖杆（0.706 / 0.746 mm 外）。
> 上一份笔记写的是「参考有杆、我方以镜像斜线代替」——本轮实测**两句都不成立**。

## 1. 窗口读数（`--window 660 352 668 372`，空冷器A）

`probe_body_against_reference --window` 印本页模型，本文件另用两个临时探针读**写出的 PDF**
与打印 primitive 的 provenance。窗口内本页只有 6 条原生图元，全部 `symbol=None`、
`stream=/Sheet6`、笔 `[0,128,0]` 0.18 mm：

| 本页笔画 | 长度 | 落在参考墨上 |
|---|---|---|
| 引线折线 6 段 | 各 1.40–1.45 | 100%，最差 0.11 mm |
| 竖管 `(664.67,370.61)->(664.67,354.52)` | 16.09 | **100%，最差 0.11 mm** |
| 横管上的记号 `(658.96,369.34)->(661.50,371.88)` | 3.59 | 100%，最差 0.04 mm |
| 竖管上的记号两条 `(665.94,363.62)->(663.40,366.16)`、`(665.94,364.89)->(663.40,367.43)` | 各 3.59 | **37%，最差 1.31 mm** |

参考页同一窗口里，竖管是 `(664.63,370.50)->(664.63,354.41)` 16.09 mm，与我们的
`664.67` 差 0.06 mm——**竖杆画了**。参考页那两条斜线的端点是
`(663.28,363.22)->(665.82,360.68)`、`(663.28,364.41)->(665.82,361.87)`：斜率与我们相同（都是 −1），
不是镜像，只是**整体高了约 3 mm**。

## 2. 这两条斜线是 stamp 出来的记号，不是记录里的线

打印 primitive 的 `byte_range` 是 `130956..131050`，与 `/Sheet6` 的 `igLineString2d`
（oid 4454，四点链 `(613.94,340.75)→(613.94,370.61)→(664.67,370.61)→(664.67,354.52)`）
同一条记录。两条斜线各 3.59 mm、相距 1.27 mm，正是 `stamp_complex_dash` 的记号字形
（`complex_dash_glyph_span_mm` 的注释：两条平行斜划，沿走向 2.5 mm、横向 2.6 mm，
斜长 3.6 mm）。

沿走向量位置：竖管长 16.09 mm，从 `(664.67,370.61)` 起点算

| | 记号中心 | 距起点 |
|---|---|---|
| 我方 | `y≈365.53` | **5.08 mm** = 样式 advance 10.16 的一半（`complex_dash_positions` 单记号规则） |
| 参考 | `y≈362.55` | **8.07 mm** ≈ 半个 16.1 mm |

横管上的那个记号两边一致到 0.55 mm（我方 45.66 / 参考 46.21 距 `x 613.94` 端），所以不是整段平移。

## 3. 判定

- **不是 H1 放置变换**：窗口里没有符号体（唯一的 `symbol` 是 `Single Function/Disc…` 的
  `circ (664.671,348.169) r 6.350` 仪表圈），两条斜线是 `/Sheet6` 原生记录上的 stamp，没有 `scale`。
- **不是 H2 层过滤**：竖管 16.09 mm 100% 落在参考墨上（最差 0.11 mm），没有被过滤掉的东西。
- **不是 H3「体里没有竖杆」**：竖杆在，且与参考差 0.06 mm。
- 余量真正落在**单记号位置规则**上：本段 16.09 mm ≈ 1.58 个 advance，`complex_dash_cells`
  取 1 格，`complex_dash_positions` 给 `period/2 = 5.08`；参考页给 8.07。

## 4. 本轮不动代码

`complex_dash_positions` 的「单记号取半个 advance」是被量过的（`docs/analysis/2026-10-24-`
`one-glyph-stubs-centre-a-half-period-in.md`：6.19 / 6.54 mm 短管上的记号落在 5.08 / 5.02）。
把它改成「取段中点」会同时推翻那批短管的读数，而本段 8.07 的含义（是否参考侧把 16.09 mm
当成更长管段的一半，还是这条样式另有 advance）**还没有独立证据**。按计划的风险条款：停在
判定、记录反证，不硬凑成因，也不改阈值。钉子维持 `8.210`。
