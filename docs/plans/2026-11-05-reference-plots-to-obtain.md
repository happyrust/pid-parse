## 拿到之后怎么接

1. 把 `.pid` 与同名 `.pdf` 放进 `验收数据`（或另立目录，设 `PID_ACCEPTANCE_CORPUS`）。
2. `cargo run -p pid-plot --example probe_style_witness -- <backup-plant-data>` 重算见证集；
   `style_witness.rs` 的钉子随之收紧（未见证集合只减不增）。
3. 在 `reference_plots_acceptance.rs` 的 `PINS` 加一行，读数先测后钉；A2 / CCHB-A1 的
   新模板若在该页上算成多画，先补 `template-masks.json` 的掩膜，再定钉子。
4. 若某个笔宽的印出值落在现档界的另一侧，那才是渲染改动；改 `pen_width_mm` 档界并在
   对比报告的 `pen` 列里看差异清零。

没有这些参考图之前，这些页面只能写「未发现可归属缺陷」，不能写「正确」
（`docs/plans/2026-10-29-plot-pdf-correctness.md` §5）。
